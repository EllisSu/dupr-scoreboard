# 🏓 DUPR 8人制記分板

專為 8 人匹克球（Pickleball）輪轉賽設計的記分板。單一 HTML 檔案、零依賴、可離線使用，分數存在瀏覽器本機。

**線上使用**：<https://ellissu.github.io/dupr-scoreboard/>

## 功能

- **賽程記分** — 14 場賽程已排定，直接填入雙方分數，勝方隊伍即時以綠色標示
- **即時排名** — 自動換算每位選手的勝、敗、得分、失分與得失分差
- **選手名單** — 輸入 A–H 八個代號對應的選手名稱，賽程表會同步顯示
- **自動保存** — 分數與名單存入瀏覽器 `localStorage`，關掉頁面或重新整理都不會遺失
- **深色模式** — 跟隨系統設定自動切換
- **手機優先** — 版面為行動裝置設計，分數欄位使用數字鍵盤，並支援瀏海螢幕安全區域

## 使用方式

1. 開啟頁面，切到「**選手**」分頁，填入 A–H 八位選手的名稱
2. 回到「**賽程記分**」分頁，依場次填入雙方比分
3. 切到「**排名**」分頁查看目前戰績（每次切換時重新計算）

要重新開始一輪比賽，按賽程頁最下方的「清除所有分數」（會保留選手名單）。

### 本機執行

下載或 clone 後直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西。

```bash
git clone https://github.com/EllisSu/dupr-scoreboard.git
cd dupr-scoreboard
start index.html          # Windows；macOS 用 open index.html
```

## 賽制

8 位選手（代號 A–H）共打 **14 場雙打**。賽程是一組平衡輪轉：

- 每位選手出賽 **7 場**
- 每位選手與其他 7 人**各搭配一次**當隊友

| 場次 | 對戰 | | 場次 | 對戰 |
|:--:|:--|:--|:--:|:--|
| 01 | H-A vs B-D | | 08 | F-C vs A-B |
| 02 | C-G vs E-F | | 09 | H-B vs C-E |
| 03 | E-B vs G-A | | 10 | D-A vs F-G |
| 04 | H-C vs D-F | | 11 | A-E vs C-D |
| 05 | B-F vs D-E | | 12 | H-F vs G-B |
| 06 | H-G vs A-C | | 13 | G-D vs B-C |
| 07 | H-D vs E-G | | 14 | H-E vs F-A |

## 排名規則

由於是輪轉賽、隊友每場不同，成績以**個人**為單位累計；雙打的分數由該場兩位隊員共同計入。

| 欄位 | 說明 |
|---|---|
| 勝 | 該選手所在隊伍得分高於對手的場數 |
| 敗 | 該選手所在隊伍得分低於對手的場數 |
| 得分 | 所有出賽場次中，所在隊伍的得分加總 |
| 失分 | 所有出賽場次中，對手隊伍的得分加總 |
| 差 | 得分 − 失分 |

名次依序比較：**勝場數** → **得失分差** → **總得分**。三項皆相同者並列同名次。前三名以金／銀／銅徽章標示。

## 資料與隱私

所有資料只存在你自己的瀏覽器 `localStorage`（`dupr_players`、`dupr_scores`），不會上傳到任何伺服器。換瀏覽器、換裝置或清除瀏覽資料都會遺失紀錄，多人同時記分也不會互相同步。
